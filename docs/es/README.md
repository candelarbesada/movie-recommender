## Convenciones de estado

- **Aprobado:** decisión confirmada durante Product Discovery.
- **Pendiente:** requiere una decisión o definición adicional.
- **Por priorizar:** está contemplado, pero todavía no se ha asignado a una entrega.
- **Riesgo / por investigar:** depende de validación externa, legal, económica o de viabilidad.

La documentación refleja decisiones de producto, no decisiones de implementación. La arquitectura, el stack, los proveedores concretos y los formatos técnicos se decidirán en sus fases correspondientes.

## Mantenimiento

Esta documentación debe ser la referencia de producto vigente. Cuando se tome una nueva decisión, se actualizará el documento correspondiente y se registrará en `product-decisions.md`. Las propuestas no deben presentarse como decisiones aprobadas sin validación explícita.
