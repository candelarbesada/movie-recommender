# Roadmap global

**Estado:** fases globales acordadas; orden, dependencias y estimaciones detalladas pendientes.

## Principios de planificación

- Entregar valor de forma incremental.
- Mantener el descubrimiento personalizado como núcleo.
- Evitar complejidad prematura y microservicios sin justificación.
- Priorizar según valor, dependencias, esfuerzo, coste y riesgo.
- No convertir todas las capacidades contempladas en compromisos del primer lanzamiento.

## Fases

| Fase | Objetivo | Estado |
|---|---|---|
| 0. Product Discovery | Definir visión, público, propuesta de valor, requisitos y dirección del MVP. | Consolidado |
| 1. Arquitectura y decisiones tecnológicas | Evaluar arquitectura, stack, proveedores y decisiones técnicas. | Siguiente fase |
| 2. Fundamentos de ingeniería | Preparar repositorio, GitHub, CI y entorno de desarrollo. | Pendiente |
| 3. Backend, persistencia e identidad | Construir capacidades base de aplicación, datos y cuentas. | Pendiente |
| 4. Catálogo y adquisición de datos | Incorporar catálogo, metadatos, imágenes y trazabilidad. | Pendiente |
| 5. Web responsive y UX | Construir experiencia de navegación, fichas y diario. | Pendiente |
| 6. Recomendador inicial | Lanzar personalización funcional y feedback de recomendaciones. | Pendiente |
| 7. Analítica personal | Incorporar dashboard personal básico. | Pendiente |
| 8. Seguridad y calidad | Verificar privacidad, seguridad, accesibilidad, calidad y fiabilidad. | Pendiente |
| 9. Despliegue y lanzamiento MVP | Preparar operación y lanzamiento inicial. | Pendiente |
| 10. Evolución | Mejorar recomendador y ampliar analítica, social, móvil y gamificación. | Futuro |

El orden es orientativo. La secuencia real deberá considerar dependencias y posibles trabajos en paralelo.

## Próxima fase

La siguiente fase es arquitectura y decisiones tecnológicas. Deberá partir de los requisitos de producto y evaluar opciones sin asumir que las tecnologías candidatas ya están aprobadas.

## Evolución posterior contemplada

- Aplicaciones móviles.
- Red social y descubrimiento entre usuarios.
- Wrapped anual y analítica avanzada.
- Gamificación y tienda cosmética.
- Integraciones adicionales.
- Mejora progresiva del recomendador.

## Criterios de avance

Cada fase deberá tener objetivos, entregables, criterios de aceptación y decisiones pendientes identificados antes de considerarse cerrada.
