# Security Policy

## Supported Versions

Movie Recommender is currently under active development.

No stable production releases are available yet. Security support policies will be defined when the project reaches its first release.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**Do not disclose security vulnerabilities publicly through GitHub Issues.**

Instead, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub.

## What to Include

Please provide as much relevant information as possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant screenshots, logs, or proof of concept, if available.

Avoid including real credentials, personal information, or sensitive user data in reports.

## Response Process

Reports will be reviewed as soon as reasonably possible.

The project owner will assess the reported issue, determine its severity, and coordinate any necessary fixes.

Please allow reasonable time for investigation and remediation before making vulnerabilities public.

## Scope

Security reports may include, but are not limited to:

- Authentication and authorization issues.
- Unauthorized access to user data.
- Exposure of credentials or sensitive information.
- Injection vulnerabilities.
- Data integrity and privacy issues.
- Other application security weaknesses.
