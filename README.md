# Movie Recommender

An intelligent movie discovery and personal cinema analytics platform.

## Overview

Movie Recommender is a platform designed to help users discover movies tailored to their interests, keep track of their cinematic journey, and understand their viewing habits through personalized recommendations and data-driven insights.

The project combines three core pillars:

- **Movie Discovery:** Personalized recommendations, intelligent search, and movie exploration.
- **Personal Cinema Journal:** Watched movies, ratings, reviews, watchlists, and custom lists.
- **Personal Analytics:** Interactive statistics, viewing patterns, and insights into individual preferences.
